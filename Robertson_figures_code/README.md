# Robertson Project — Figure Package (Figures 1–10)

This package contains everything needed to reproduce the ten figures of the
report *Numerical Solution of the Robertson Problem* (Team E).

## Layout

```
code/      all Python sources (model, solvers, experiments, figure scripts)
results/   experiment data (.npz + summary.json) read by make_figures.py
figures/   the ten report figures (PNG previews + PDF for LaTeX)
```

## Figure ↔ code mapping

| Report figure | File base name      | Generated by                                   |
|---------------|---------------------|------------------------------------------------|
| Figure 1      | fig_solution        | code/make_figures.py :: fig_solution()         |
| Figure 2      | fig_refcheck        | code/make_figures_supplementary.py :: fig_refcheck() |

Note: Figure 10 is shipped as PNG only (raster), matching the report.

## How to regenerate

```bash
pip install -r code/requirements.txt

# (optional) re-run all experiments from scratch (a few minutes),
# refreshing results/*.npz and results/summary.json:
python code/run_all.py

# Figures 1, 3–9  (read from results/):
python code/make_figures.py

# Figure 2 (recomputes the two Radau reference runs; deterministic,
# no stored data needed) and Figure 10 (benchmark timings):
python code/make_figures_supplementary.py
```

### Figure 10 timings

Wall-clock timings are machine-dependent. `fig_matchedcost()` plots the
values measured on the report's benchmark machine (Python 3.12.14, NumPy
2.2.6, SciPy 1.15.3; macOS 26.6.2 arm64), which are stored in the script.
To re-measure on your own machine (one warm-up run + five timed runs,
minimum reported; protocol in Appendix C.2 of the report):

```bash
python code/make_figures_supplementary.py --rerun
```

Absolute times will differ; the EE-vs-IE ratio at matched error should
remain close to the reported 5.16–5.25 range.
